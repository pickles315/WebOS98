# WebOS 98

A little Windows 98-inspired desktop that runs in your browser. This replaces the previous TinyGames project in this repository.

## Run it
Open `index.html`, or enable GitHub Pages in Settings → Pages and deploy from the `main` branch, root folder.

## Included
- Retro desktop, icons, Start menu, taskbar and draggable windows
- My Computer and My Documents
- Notepad with browser-local saving
- DOS-style terminal (`help`, `dir`, `cls`, `ver`, `date`, `time`, `echo`, `about`)
- Simulated Internet Explorer with external links
- Wallpaper settings saved locally
- Minesweeper mini-game
- Responsive layout for smaller screens

## Tech
Plain HTML, CSS and JavaScript. No build step, backend, account, or paid service is required. Notepad text and wallpaper preferences are stored in localStorage on the current browser.

WebOS 98 is a fan-made retro desktop simulation, not an actual Microsoft operating system.
